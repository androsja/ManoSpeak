# Commands Reference — ManoSpeak

This document indexes all short DWP alias commands configured under the `.agents/commands/` directory.

| Command | Action |
| :--- | :--- |
| `/dwp-create` | Create a new Deep Work Plan draft based on a specified task goal. |
| `/dwp-execute` | Run the active DWP plan task-by-task, validating each gate. |
| `/dwp-refine` | Adjust, insert, or reorder tasks in an active or draft plan. |
| `/dwp-resume` | Recover state and continue executing a paused plan. |
| `/dwp-status` | Display plan tasks status (complete, in-progress, pending). |
| `/dwp-verify` | Validate repository state conformance. |
| `/agent-create` | Author or update an agent persona MD profile. |
| `/skill-create` | Author or update a custom development skill MD profile. |
