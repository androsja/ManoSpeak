# LSC Reference Manuals

This folder keeps downloaded references for future review of Colombian Sign
Language (LSC) signs and motion drafts. The files are research references; they
are not a substitute for review by Deaf LSC users or regional signers.

## Downloaded PDFs

| File | Reference | Useful sections | Review status |
| --- | --- | --- | --- |
| `elementos-didactica-lsc-y-matematicas-estudiantes-sordos.pdf` | Dora Inés Calderón and Olga Lucía León Corredor, *Elementos para una didáctica del lenguaje y las matemáticas en estudiantes sordos de niveles iniciales*, Editorial Universidad Distrital Francisco José de Caldas, 2016. [Source PDF](https://repository.udistrital.edu.co/server/api/core/bitstreams/d0377a58-82c3-4c9a-a050-66670890541f/content) | Printed pages 94–96 describe LSC number formation. The text says six is made with the palm forward, extending and flexing the index while the other fingers stay folded. | Used as the initial reference for the SIX motion draft; regional review remains pending. |
| `diccionario-basico-lsc-insor-mineducacion.pdf` | Instituto Nacional para Sordos (INSOR) and Instituto Caro y Cuervo, *Diccionario básico de la Lengua de Señas Colombiana*, Ministerio de Educación Nacional, 2006. [Source PDF](https://www.colombiaaprende.edu.co/sites/default/files/files_public/2022-04/Diccionario-lengua-de-senas.pdf) | Lexical entries and LSC usage examples. | Pending review. |
| `diccionario-lsc-signwriting-2023.pdf` | *Lengua de Señas Colombiana (LSC)*, SignWriting Dictionary, dated 2023-09-05. [Source PDF](https://signwriting.org/archive/docs14/sw1378_Diccionario_Lengua_Senas_Colombiana_2023_0905.pdf) | SignWriting records and gloss lookup. | Pending review. |
